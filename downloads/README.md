# Catalog downloads

Selected original installation packages and extracted runtime repacks are hosted as assets in this repository’s [Original](https://github.com/Vyrsace/DAKnow/releases/tag/downloads-original) and [Repack](https://github.com/Vyrsace/DAKnow/releases/tag/downloads-repack) releases. GitHub’s 100 MiB Git file limit prevents storing all ZIPs directly in these folders. The indexes below record the exact selected filenames, verified byte counts, SHA-256 hashes and direct download links.

- [Original packages](original/README.md)
- [Runtime repacks](repack/README.md)
